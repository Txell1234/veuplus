1. ✅ Leer [CHANGELOG_v2.1.0.md](CHANGELOG_v2.1.0.md)
2. ✅ Hacer backup de la base de datos
3. ✅ Actualizar código: `git pull`
4. ✅ Actualizar dependencias: `pip install -r requirements.txt --upgrade`
5. ✅ Actualizar frontend: `cd frontend && npm install`
6. ✅ Revisar nuevas variables en [config.example.env](config.example.env)
7. ✅ Ejecutar `python verificar_instalacion.py`
8. ✅ Reiniciar servicios
